ログインの練習

Kagibako の自動入力を試すためのページです

このページは練習用です。入力した内容はどこにも送られません（このページには送信する仕組みがありません）。本物の ID・パスワードは入れないでください。

ID とパスワードの両方を入れてください。

入力できました！ これで練習はおしまいです。Kagibako に戻ってください。

やり方

  1. 上の「ID」の欄を押します
  2. キーボードの上か、欄の下に出る「Kagibako で入力」を押します
  3. Kagibako のロックを解除して、練習用のアイテムを選びます
  4. ID とパスワードが入ると、「入力できました！」と出ます

「Kagibako で入力」が出ないとき

  • Kagibako の 設定 で「自動入力サービス」に設定しているか確かめてください。
  • Chrome・Brave：ブラウザの 設定 →「自動入力サービス」→「他のサービスを使用して自動入力」を選び、ブラウザを再起動してください。
  • ID の欄を一度押しただけでは出ないことがあります。もう一度押してみてください。
  • Galaxy の「Samsung インターネット」では、ほかのアプリの自動入力が出ないことがあります。Chrome で開き直してください。
