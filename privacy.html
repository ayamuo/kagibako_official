プライバシーポリシー

Kagibako（鍵箱）／最終更新：2026年11月20日

このポリシーの対象

このポリシーは、ayamuo（以下、提供者）が提供するパスワード管理アプリ「Kagibako（鍵箱）」（以下、本アプリ）の、次の版に適用されます。

  • スマホアプリ（Android 版）
  • スマホアプリ（iOS 版）
  • Windows 版

基本方針

本アプリは、ID やパスワードを利用者自身が管理するためのアプリです。本アプリで管理するデータは、暗号化したまま、利用者が選んだ場所にだけ保存され、提供者のサーバーや第三者へ送信されることはありません。本アプリはアカウント登録を必要とせず、氏名・メールアドレスなどの個人情報を収集しません。

保存されるデータ（全体に共通）

ID・パスワード・メモなどのデータは、Argon2id と AES-256-GCM で暗号化した .kagi ファイルに保存されます。ファイルの保存場所は利用者が選びます。クラウドストレージ（Google ドライブ・OneDrive など）に保存した場合、そのファイルの取り扱いには各クラウドサービスの規約が適用されます（ファイルは暗号化されたまま保存されます）。

このほか、本アプリは次の情報を端末の中にだけ保存します。

  • 設定（画面の色、自動ロックの時間など）
  • 古いファイルでの上書きを見つけるための、ファイルの控え（暗号化したまま。最大30版）
  • ロックしたときの未保存の変更（暗号化したまま）
  • 最近使ったファイルの一覧

クリップボード（全体に共通）

コピーした ID やパスワードは、一定時間（初期設定では30秒）後にクリップボードから消去します。

広告・アクセス解析・第三者への提供（全体に共通）

本アプリは、広告の表示、アクセス解析、トラッキングを行いません。提供者は、利用者のデータを第三者へ提供しません。そもそも、利用者のデータを受け取る仕組みがありません。

スマホアプリ（Android 版）

通信

インターネットに接続する権限を持たない作りです。データを外部へ送ることはできません。

使う権限

  • 指紋・顔の認証（指紋・顔でのロック解除を使う場合のみ）
  • 自動入力サービス（利用者が Kagibako を自動入力サービスに設定した場合のみ）

ファイルの読み書きは、Android のファイル選択画面で利用者が選んだファイルに限られます。

ほかのアプリへの自動入力

利用者が Kagibako を自動入力サービスに設定した場合、入力欄の種類と、入力先のサイトのドメインやアプリの名前を Android から受け取り、合うアイテムを探すために使います。アプリで選んだアイテムを次回から上に出すため、「アプリの名前と選んだアイテム」の組み合わせを端末の中にだけ保存します。

指紋・顔でのロック解除

指紋や顔の情報そのものに、本アプリが触れることはありません（判定は Android が行います）。設定した場合、マスターパスワードは端末のセキュリティ領域（Android Keystore）の鍵で暗号化して端末の中に保存し、指紋や顔が通ったときだけ取り出します。設定はいつでも取り消せます。

そのほか

  • 本アプリのデータは、端末のクラウドバックアップや端末間の移行の対象から外しています。
  • 本アプリの画面は、スクリーンショットや画面の録画ができないようにしています。
  • コピーしたパスワードは、パスワードであることを Android に伝え、通知などに表示されにくくしています。
  • 「このアプリを友達に紹介する」は、紹介文とこのサイトのアドレスを、利用者が選んだアプリに渡すだけです。管理しているデータは含まれません。

Windows 版

通信

本アプリ自身はインターネット通信を行いません。「公式サイトを開く」などのリンクを押したときは、Windows の既定のブラウザでそのページを開きます。画面の表示に使っている Microsoft Edge WebView2 ランタイムの取り扱いは、マイクロソフトのプライバシーに関する方針に従います。

自動入力のときに読み取る情報

自動入力の直前に、入力先のウィンドウの名前と、ブラウザのアドレスバーに表示されているアドレスを読み取り、登録した公式サイトのドメインと照らし合わせます（偽サイト対策）。読み取った情報は照合にだけ使い、保存も送信もしません。ページの中身は読み取りません。

そのほか

  • 保存のたびに、暗号化したままのファイルを自動でバックアップします（初期設定では「ドキュメント\Kagibako\backup」。設定で変更・停止できます）。
  • コピーした ID やパスワードは、クリップボードの履歴とクラウドへの同期に残らない形でコピーします。
